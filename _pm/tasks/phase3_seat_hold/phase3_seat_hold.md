# 3단계: 좌석 선점 (자동)

## 목적
예매 오픈 시점에, 회원님이 로그인해둔 브라우저에서 미리 지정한 선호 좌석 중
남은 자리를 파악해 자동 선택 → 결제 페이지로 진입해 **좌석을 선점**한다.
(결제 자체는 회원님이 그 창에서 직접 완료)

## 배경 / 사용자 관찰
- CGV는 로그인 상태에서 좌석 선택 후 결제 페이지로 넘어가면 좌석이 선점(lock)됨
  → 다른 브라우저에서 해당 좌석 선택 불가 확인됨
- 좌석 선택은 **로그인 필수** (미로그인 시 상영시간 클릭하면 안내 모달만, 진행 불가) — 2026-09-02 확인
- 2단계 감시는 그대로 유지

## 설계
1. **로그인 세션 확보**: 전용 Playwright 영속 프로필(`data/browser_profile`)
   - `scripts/login_setup.py` (headed): 회원님이 1회 로그인 → 쿠키 프로필 저장
   - `scripts/login_check.py`: SSO `getCjssoq`의 `ssoMbrNo`로 로그인 상태 판별
   - 이 프로필 창이 곧 "회원님이 로그인해둔 브라우저"가 됨
2. **좌석맵 파악**: 상영시간(siteNo, scnYmd, scnsNo, scnSseq) → 좌석 조회 API/DOM 매핑 (탐색 필요, 로그인 후)
3. **선호 좌석 선택**: watchlist에 preferred_seats(예: ["G7","G8"]) 또는 구역/열 우선순위
   - 남은 좌석 중 선호 우선순위대로 선택
4. **선점**: 인원 선택 → 좌석 선택 → 결제 페이지 진입까지 자동. 결제 직전 정지.

## 확보된 API (탐색 진행 중)
- 상영시간 클릭 시: `common/bznsCom/mov/searchRtktCntlYn?...&scnsNo=&scnSseq=&rtctlScopCd=08` (재예매 통제 여부)
- 좌석 조회 API: (로그인 후 탐색 예정)

## 안전성 / 윤리
- 회원님 본인 관람 목적의 개인 자동화 (정당한 사용)
- 좌석 선점 후 결제 안 하면 CGV가 일정 시간 뒤 자동 해제 → 테스트 시 과도한 반복 금지
- 크레덴셜은 저장/전송하지 않음 (브라우저 프로필 쿠키만 로컬 보관, git 제외)

## 미결정 사항
- 선호 좌석 지정 방식 (정확한 좌석번호 vs 구역/열 선호도)
- 인원 구성 (성인 N명 등) 지정 방식
- 결제까지 자동화할지, 좌석 선점까지만 하고 사람이 결제할지 (현재: 선점까지)
