# 1단계: 예매 오픈일 추측

## 목적
CGV 개봉예정작 목록을 주기적으로 수집하여, 각 영화의 **예매 오픈 시점을 추측**한다.
2단계(오픈 감지+알림)의 기반 데이터가 된다.

## 배경
- CGV는 예매 오픈 일시를 사전 공지하지 않는 경우가 많음 (대작은 공지하기도 함)
- 통상 개봉일 1~2주 전 예매 오픈, 대작(마블/대형 한국영화)은 2~3주 전
- 과거 오픈 이력을 축적하면 추측 정확도를 높일 수 있음

## 설계
1. **수집**: Playwright(headless Chromium)로 CGV 개봉예정작 페이지 접근
   - CGV 신규 사이트는 Next.js + 내부 JSON API → 브라우저 컨텍스트에서 API 응답 캡처
   - Cloudflare 보호로 단순 requests 불가 (curl 403 확인됨)
2. **저장**: `data/snapshots/{YYYYMMDD_HHMMSS}.json` — 영화별 (제목, 개봉일, 예매가능 여부, 예매율)
3. **감지**: 이전 스냅샷과 비교 → "예매불가 → 예매가능" 전환 시점 = 실제 오픈 시점 기록 (`data/open_history.json`)
4. **추측**: 개봉일 기준 규칙(리드타임) + 축적된 이력 기반 보정
   - 초기 규칙: 일반 영화 D-14, 대작 D-21 (이력 쌓이면 통계로 대체)

## 수정 대상 파일
- `src/cgv/browser.py` — Playwright 헬퍼
- `src/cgv/upcoming.py` — 개봉예정작 수집
- `src/predictor.py` — 오픈일 추측
- `src/storage.py` — 스냅샷/이력 저장
- `src/main.py` — CLI
